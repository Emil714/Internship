# ML Task — Walmart Sales Prediction

## Задача

Вам предоставлен датасет с историей еженедельных продаж магазинов Walmart.

Необходимо построить ML-модель для прогнозирования `Weekly_Sales`.

## Что нужно сделать

1. Провести небольшой EDA:
   - проверить пропуски и дубликаты;
   - проанализировать продажи;
   - показать 2–3 информативных графика.

2. Подготовить данные:
   - обработать `Date`;
   - создать полезные признаки;
   - разделить данные на train/test **по времени**, без случайного `train_test_split`.

3. Обучить ML-модель для прогнозирования `Weekly_Sales`.

   Можно использовать:
   - Linear Regression;
   - Random Forest;
   - XGBoost / LightGBM / CatBoost.

4. Оценить качество модели с помощью:
   - MAE;
   - RMSE;
   - MAPE.

5. Сравнить **фактические и предсказанные продажи** на тестовой выборке.

6. Кратко описать:
   - какие признаки были созданы;
   - какую модель выбрали и почему;
   - полученные результаты.

## Bonus

Будет плюсом:

- создание `lag` / `rolling` признаков;
- сравнение нескольких моделей;
- hyperparameter tuning;
- аккуратная структура Python-кода.

## Результат

Необходимо предоставить:

```text
project/
├── README.md

```

Оценивается не только итоговая метрика, но и качество preprocessing, feature engineering, корректность разделения временных данных и понимание выбранного подхода.
