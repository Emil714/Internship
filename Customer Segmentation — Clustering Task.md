# Customer Segmentation — Clustering Task

Dataset: `c8205f4d-e31d-4c75-81ae-9461f2b7a786.csv`

## Задание

Используя метод **K-Means Clustering**, разделите клиентов из данного датасета на отдельные сегменты.

Выполните следующие шаги:

1. Загрузите датасет и проведите **первичный анализ данных**: проверьте missing values, дубликаты и основные статистические показатели.
2. Выберите необходимые для кластеризации признаки и выполните их **масштабирование (scaling)**.
3. Для значений `K=2...10` используйте **Elbow Method** и определите оптимальное количество кластеров.
4. Обучите модель **K-Means** с выбранным значением `K`.
5. Визуализируйте полученные кластеры с помощью графиков.
6. Определите основные характеристики каждого кластера и дайте им краткие названия.

### В результате

В Jupyter Notebook должны присутствовать:

- Первичный анализ данных
- Preprocessing + Scaling
- Elbow Method
- K-Means
- Visualization
- Cluster Analysis
